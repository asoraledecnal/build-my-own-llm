# build-my-own-llm

A small language model built from scratch as a learning project. The goal is to understand how a transformer is trained, not to compete with large commercial models.

## Status

Planning. No model has been trained yet.

## Plan

1. Pick a small text dataset and write it up (source, size, license).
2. Build a character- or BPE-level tokenizer.
3. Implement a small decoder-only transformer, following nanoGPT as a reference.
4. Train on a laptop or a free Colab/Kaggle GPU. Record training time, hardware, and the loss curve.
5. Generate sample text and write up what worked and what did not.
